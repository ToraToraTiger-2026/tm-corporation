PROJECT STORY 02

ウェブサービス事業

誰かの小さな不便を、社会を変えるサービスへ。

お酒を飲まない人が、気兼ねなく入れるお店を探せたら。たった一つの違和感を企画に変え、利用者の声で育て続けてきた「下戸マップ」。その担当者が、うまくいかなかったことも含めて語ります。

  • 継続的な改善

ウェブサービス事業

「下戸マップ」企画・開発・改善プロジェクト
登場社員
日野 拓海

01Background

「飲まない」を、不便にしないために

飲み会のお店選びは、お酒を飲むことを前提に情報が整理されがちです。メニューにはお酒の種類ばかりが並び、「まずは乾杯で」という空気もある。お酒を飲まない人は、そんな場で、小さな気まずさを抱えながら過ごすことがあります。

大きな問題ではありません。けれど、確かにそこにある不便です。「お酒を飲まない人でも入りやすいお店」を探せるウェブサービス「下戸マップ」は、その不便に光を当てることから始まりました。

02Origin

幹事を務めた夜の、小さな違和感

きっかけは、サービス企画部の日野 拓海が、飲み会の幹事を務めた夜でした。お酒を飲まない後輩が、最後まで一杯のウーロン茶を手に、控えめに座っていたのです。

お店を選んだのは自分でした。後輩が悪いわけではなく、お店選びの側の問題ではないか。幹事のたびに、ソフトドリンクの種類を電話で確かめていた手間も重なりました。「飲まない人が居づらくないお店を探せる地図があれば」。日野は、その思いを企画書にまとめはじめます。

03Challenge

「ニッチでは?」と言われた企画会議

最初の企画会議は、厳しい質問の連続でした。「飲まない人向けだけで、市場は十分なのか」「お店側には、どんなメリットがあるのか」。日野は、答えに詰まりました。

反論より先に、日野が選んだのは、聞いて回ることでした。社内外の、お酒を飲まない人や幹事の経験がある人に、お店選びで困った場面を聞いていきます。意見ではなく、具体的な声で語れるようにするためです。

04Insight

本当に求められていたのは、何だったのか

ヒアリングで見えてきたのは、日野の想定とは少し違う景色でした。日野が重視していたのは「ノンアルコール飲料があるか」でしたが、多くの人が気にしていたのは、「飲まなくても居づらくない雰囲気か」「食事の選択肢が十分にあるか」「ソフトドリンクが充実しているか」といった点でした。

日野は、投稿してもらう項目を作り直しました。ノンアルコールの有無だけでなく、お店の雰囲気、食事の選びやすさ、席の使い方まで、利用者が感じたことを残せる形にしたのです。

05Development

開発の壁と、公開前の仕様変更

開発では、地図の表示が重く、スマートフォンで動きがぎこちないという問題が出ました。日野は、ITコンサルティング事業の開発メンバーと一緒に、地図と検索の仕組みを見直し、表示を軽くしていきます。

仕様の大きな変更もありました。誰でも気軽に投稿できるよう、個人情報を取得しない匿名投稿にしたのです。ただし匿名には、不適切な投稿や誤った情報が混ざるリスクがあります。議論の末、投稿は運営が確認してから掲載する仕組みに決まりました。公開の時期を見直す判断にもなりました。

Project Flow

プロジェクトの流れ

  1. 1

    違和感を見つける

    幹事を務めた夜の気づきを、企画書にまとめる。

  2. 2

    声を聞いて回る

    お酒を飲まない人や幹事経験者にヒアリング。

  3. 3

    項目を作り直す

    雰囲気や食事の選びやすさまで残せる形に。

  4. 4

    仕組みを整える

    地図の表示を軽くし、匿名投稿と運営確認を設計。

  5. 5

    公開して育てる

    利用者の声と数値をもとに、改善を続ける。

06After Launch

公開してわかった、想定外の課題

公開後すぐに、想定していなかった課題が次々に見つかりました。誤った情報が載ってしまったお店からの、掲載内容の訂正や削除の依頼。評価が偏った投稿。投稿の質にも、ばらつきがありました。

チームは、お店からの依頼を受け付ける窓口を設け、運営での確認の基準を整えました。「投稿を増やす施策」より、まず「信頼できる情報にする施策」を優先する。地味な判断でしたが、サービスを長く育てるうえで欠かせないものでした。日野は今も、利用者の投稿と数値の両方を見ながら、改善案を考え続けています。

07Result

小さな不便を見える形にすることの意味

「下戸マップ」は、飲み会の場所を選ぶときの手がかりとして使われるようになりました。蓄積された投稿は、ノンアルコールの需要やお店選びの傾向を知る材料にもなり、飲食店や自治体に向けた調査レポートとして活用されています。

お店にとっても、これまで気づきにくかった客層を知るきっかけになります。誰かの小さな不便を見える形にすることが、お店と利用者の、新しい出会いにつながっていく。それがこのサービスの社会的な意義だと、チームは考えています。

08Growth

ゼロから育てる難しさと、やりがい

サービスは、公開して終わりではありません。投稿を確認し、声に耳を傾け、小さな改善を積み重ねる。地道な日々のなかで、日野は「気兼ねなくお店を選べた」という利用者の声に、何度も励まされてきたといいます。

入社数年目の社員の企画が、本当にサービスになる。それを後押ししてくれたのは、失敗しても、まず試してみようと言ってくれる、上司や先輩、そして開発や運営のメンバーでした。

Message

就職活動中のみなさんへ

日常の中で感じた小さな違和感を、「気のせい」で終わらせないでください。それが誰かの困りごとかもしれないと確かめにいく行動が、新しいサービスの始まりになります。うまくいかないことも多いですが、一緒に悩み、育てていける仲間がここにいます。

  • 日野 拓海あなたの「ちょっと不便だな」を、ぜひ聞かせてください。

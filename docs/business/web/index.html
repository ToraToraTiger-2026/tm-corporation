Web Services

ウェブサービス運営

「お酒を飲まない人でも入りやすいお店」を探せるウェブサービス「下戸マップ」の運営を主な事業としています。利用者の投稿をもとにしたマップで、飲み会の場所選びなどを手助けします。

2026年3月期の売上高:18億円

Services

サービス内容

下戸マップの運営

お酒を飲まない人でも入りやすいお店の情報を、利用者の匿名の投稿でマップにまとめています。投稿は、運営の確認を経て掲載されます。

掲載内容の管理・削除依頼の受付

お店の方からの、掲載内容の訂正や削除の依頼を受け付ける窓口を設け、運営チームが対応しています。

ノンアルコール需要の調査

投稿の傾向をもとに、ノンアルコールの需要や、お店選びの傾向を調査し、飲食店や自治体にレポートを提供しています。

下戸マップを見る(外部サイト・新しいタブで開きます)

Strengths

強み

匿名で安心して投稿できる設計

投稿者の個人情報を取得せずに利用できる仕組みを採用しています。

運営による確認体制

投稿内容を運営が確認してから掲載し、不適切な投稿や誤った情報を防ぎます。

グループの知見の活用

地図や検索の仕組みは、ITコンサルティング事業と連携して開発・運用しています。

Web Services

ウェブサービス運営

1996年の事業開始以来、生活に身近なウェブサービスを運営しています。使いやすさと安心してご利用いただける仕組みづくりを大切にしています。

2026年3月期の売上高:494億円(ダミーデータ)

Services

サービス内容

TMマルシェ(産直ECモール)

全国の生産者から、農産物や加工品を直接購入できるオンラインのモールです。

TMトラベル(比較・予約)

宿泊や体験プランを比較し、予約できるサービスです。地域の事業者の集客を支援します。

TMコミュニティ

趣味や地域ごとの情報交換ができるサービスです。利用規約にもとづく投稿の確認体制を整えています。

Strengths

強み

安心して使える運営体制

個人情報の保護と投稿内容の確認を重視し、専任チームが運営しています。

加盟店との継続的な関係

約9,500店舗の加盟店に、売れ行きの分析や商品ページの改善提案を行っています。

グループの決済・物流の活用

グループの電子決済や、農業事業の出荷網を活用し、購入から配送までを円滑に提供します。

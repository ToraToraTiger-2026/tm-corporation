Philosophy

企業理念

誠実に向き合い、信頼を積み重ね、社会に貢献する。これが私たちの変わらない姿勢です。

Mission

ミッション

信頼を礎に、人と産業の未来を育てる。

私たちは、金融・農業・ウェブ・ITコンサルティングという異なる分野の事業を通じて、お客様と社会の課題に向き合います。目先の成果だけでなく、長く信頼していただける関係づくりを大切にしています。

Vision

ビジョン

4つの事業の知見をつなぎ、暮らしと産業の基盤を支えるグループを目指します。農業とITコンサルティングの連携による食の安定供給、金融とウェブの連携による事業者支援など、事業の垣根を越えた価値の創出に取り組みます。

Values

行動指針

誠実であること

法令と社会規範を守り、お客様や取引先に対して正直に行動します。

信頼を積み重ねること

約束を守り、継続的な改善を通じて、安心してご利用いただけるサービスを提供します。

社会に貢献すること

事業を通じて、地域社会と環境の持続可能性に貢献します。
